# Contributing to Astria

Thanks for helping make Astria better.

1. Create a focused branch from `main`.
2. Keep UI changes aligned with `DESIGN.md`.
3. Run `npm run typecheck`, `npm run lint`, and `npm run build`.
4. Include screenshots for visible changes and describe state coverage.
5. Open a pull request with a concise explanation of the problem and solution.

Please avoid bundling unrelated refactors into feature or bug-fix pull requests.
