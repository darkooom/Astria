# Changelog

All notable changes to Astria are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.1] - 2026-10-02

### Added

- GitHub Actions checks for type safety, linting, and production builds.
- Bug report, feature request, and pull request templates.
- Dependabot configuration for weekly dependency updates.
- Private vulnerability reporting guidance and a dedicated security contact path.
- Repository social preview, product screenshots, and a production-focused README.

## [0.1.0] - 2026-10-02

### Added

- Responsive multi-tenant dashboard shell with dark and light themes.
- Dashboard, activity, member, role, usage, API key, webhook, audit log, billing, and settings views.
- Provider-neutral data, authentication, and billing contracts.
- Ready-to-run demo adapters with sample workspace data.
- PostgreSQL/Prisma, Auth.js, Clerk, and Stripe example adapters.
- Loading, empty, error, dialog, command menu, and responsive navigation states.
